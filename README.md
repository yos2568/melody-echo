# เล่นตามทำนอง

คีย์บอร์ดบนจอ C4 ถึง C5 เกมจะเล่นทำนองและทำให้คีย์สว่างตาม แล้วถึงตาคุณเล่นตาม

ฝึกความจำทำนอง รู้จักตำแหน่งโน้ตบนคีย์บอร์ด และรู้จักเพลงที่คุ้นหู 14 เพลง

## วิธีเปิด

ดับเบิลคลิก `index.html` เปิดด้วย Chrome หรือ Edge ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องต่ออินเทอร์เน็ต
เปิดบนมือถือได้เหมือนกัน เล่นด้วยนิ้ว เมาส์ หรือแป้นคอมพิวเตอร์ก็ได้

แป้นคอมพิวเตอร์: `A W S E D F T G Y H U J K` ตรงกับคีย์ C ถึง C สูงตามลำดับ (แถวกลางคือคีย์ขาว แถวบนคือคีย์ดำ)

## โหมดเล่น

| โหมด | เล่นอย่างไร |
|---|---|
| ต่อทำนอง | ทำนองยาวขึ้นทีละตัวทุกรอบ เล่นตามให้ได้ไกลที่สุด มี 3 ชีวิต |
| เรียนเพลง | เล่นตามทีละท่อนของเพลงที่เลือก พอครบเพลงจะเผยชื่อและเก็บเข้าสมุดเพลง |
| ฟังอย่างเดียว | คีย์ไม่สว่างให้ดู ต้องใช้หูฟังแล้วเล่นตาม (ต้องใช้เสียง) |
| เล่นอิสระ | กดคีย์เล่นตามใจ ไม่มีคะแนน |

ระดับ ง่าย กลาง ยาก ต่างกันที่จำนวนคีย์ที่ใช้ (5, 8 และ 13 เสียง) ความยาวของท่อน และระดับของเพลง
เหรียญสะสมและสมุดเพลงอยู่ที่หน้าแรก

## ไฟล์เดียว ห้าโซน

ทั้งเกมอยู่ในไฟล์ `index.html` ไฟล์เดียว ในส่วน `<script>` แบ่งเป็นห้าโซน ค้นหาด้วยคำว่า "โซน A" ถึง "โซน E"

| โซน | มีอะไร | แก้ได้ไหม |
|---|---|---|
| A · ข้อมูล | คีย์ ชุดคีย์ ระดับ โหมด **เพลง (`TUNES`)** เหรียญ และข้อความภาษาไทยทั้งหมด (`TEXT`) | แก้ได้ |
| B · ตั้งค่า | ตัวเลขของเกม เช่น จำนวนชีวิต จังหวะ คะแนน (`CONFIG`) | แก้ได้ |
| C · แกนเกม | ตัวคิดของเกม เช่น สร้างทำนอง ตารางเวลา คิดคะแนน | **ห้ามแก้** |
| D · หน้าจอและเสียง | วาดคีย์บอร์ด เล่นเสียง เก็บสถิติ ปุ่มตรวจระบบ | ห้ามแก้ถ้าไม่จำเป็น |
| E · ส่วนเสริม | ว่างไว้ให้เขียนความสามารถใหม่ | เขียนที่นี่ |

หน้าตาแก้ได้ที่ส่วน `<style>` ด้านบนของไฟล์ ทุกสีและขนาดเป็นตัวแปร CSS ที่มีคำอธิบายภาษาไทยกำกับ
(กลุ่ม "สีหลัก" "ขนาดและระยะ" และ "สีของเกม") เปลี่ยนค่าตรงนั้นแล้วทั้งเกมเปลี่ยนตาม

### เพิ่มเพลงของตัวเอง

เพิ่มหนึ่งบล็อกในตาราง `TUNES` ในโซน A เพลงจะโผล่ในรายการเพลงของระดับนั้นเอง ไม่ต้องแก้ที่อื่น

```js
{
  id: 'mine',
  title: 'ชื่อเพลง',
  by: 'ผู้แต่งหรือที่มา',
  level: 1,
  bpm: 100,
  notes: 'C4:1 E4:1 G4:1 C5:2'
}
```

`notes` คือโน้ตต่อกันด้วยช่องว่าง แต่ละตัวเขียนว่า `รหัสคีย์:จำนวนจังหวะ` (รหัสคีย์เช่น `C4` `Fs4` `C5`)
ต้องมีอย่างน้อย 4 ตัว ถ้าเขียนผิด เพลงจะถูกข้ามและปุ่ม **ตรวจระบบ** จะบอกว่าผิดตรงไหน

## ตัวช่วยสำหรับโซน E

เหตุการณ์ที่ฟังได้ด้วย `Game.on('ชื่อเหตุการณ์', function (detail) { ... })`

| เหตุการณ์ | `detail` |
|---|---|
| `screenChange` | `{ from, to }` |
| `gameStart` | `{ mode, level, tuneId }` |
| `playbackStart` | `{ length, bpm, lit }` ตอนเริ่มเล่นทำนอง |
| `playbackEnd` | `{ length }` |
| `notePress` | `{ keyId, midi, expected, correct, index }` (โหมดเล่นอิสระ `expected` กับ `correct` เป็น `null`) |
| `roundWon` | `{ round, length, points, mistakes }` |
| `roundLost` | `{ round, livesLeft, triesLeft }` |
| `scoreChange` | `{ score, delta, streak }` |
| `tuneLearned` | `{ tuneId, title }` |
| `badgeEarned` | `{ id, name }` |
| `gameEnd` | `{ mode, level, tuneId, score, stars, length, solved, mistakes }` |

ตัวช่วยที่เรียกได้

| ตัวช่วย | ทำอะไร |
|---|---|
| `Game.getSequence()` | รายการรหัสคีย์ของทำนองที่กำลังเล่นตาม |
| `Game.playSequence(keyIds, bpm, lit)` | เล่นรายการคีย์ให้ฟัง (`lit` คือให้คีย์สว่างหรือไม่) คืนเวลารวมเป็นมิลลิวินาที ถ้ากำลังเล่นอยู่ไม่ทำอะไร |
| `Game.replay()` | ฟังอีกครั้ง ตามขีดจำกัดของโหมด |
| `Game.playKey(keyId, durSec)` | เล่นเสียงคีย์เดียว |
| `Game.highlightKey(keyId, ms)` | ทำให้คีย์สว่างชั่วครู่ |
| `Game.setWave('sine' / 'triangle' / 'square' / 'sawtooth')` | เปลี่ยนเสียง (บันทึกไว้) |
| `Game.addLife()` | เพิ่มชีวิตหนึ่งในโหมดต่อทำนอง (ไม่เกินจำนวนเริ่มต้น) |
| `Game.showToast('ข้อความ')` | แสดงข้อความสั้น ๆ |
| `Game.getState()` / `Game.getStats()` | ดูสถานะตอนนี้ / สถิติที่เก็บไว้ (อ่านอย่างเดียว) |
| `Game.Core` | ฟังก์ชันของโซน C |

ช่องว่างที่วางปุ่มหรือข้อความได้ (เป็น `div` ว่างในหน้า ใช้ `document.getElementById('...')`)
`slotHome` หน้าแรก · `slotHud` แถบคะแนน · `slotActions` ข้างปุ่มหลัก · `slotPanel` ใต้คีย์บอร์ด · `slotResult` หน้าสรุป

ถ้าส่วนเสริมที่เขียนมีข้อผิดพลาด เกมจะเล่นต่อได้ และข้อความผิดพลาดจะไปแสดงที่ปุ่ม **ตรวจระบบ**

## เมนู feature สำหรับการสอบ

เลือกอย่างน้อย 2 อย่าง (หรือคิดเองแล้วเขียนไว้ใน spec) ข้อ 1 และ 7 เป็นข้อที่ง่ายที่สุด

1. **ทำนองของฉัน** เพิ่มเพลงสองเพลงใน `TUNES` (เพลงที่แต่งเอง หรือเพลงสาธารณสมบัติจากเครื่องดนตรีของตัวเอง)
2. **ฟังช้า ๆ** ปุ่มที่ใช้ได้สามครั้งต่อเกม เล่นทำนองปัจจุบันซ้ำด้วยความเร็วครึ่งหนึ่ง (ใช้ `Game.getSequence` `Game.playSequence`)
3. **อัดแล้วเล่นย้อน** ในโหมดเล่นอิสระ บันทึกคีย์ที่กด แล้วเล่นย้อนให้ฟัง (ใช้ `notePress` `Game.playSequence`)
4. **เสียงของฉัน** ตัวเลือกเสียงที่หน้าแรก (ใช้ `Game.setWave`)
5. **ชีวิตพิเศษ** ในโหมดต่อทำนอง ได้ชีวิตคืนหนึ่งดวงทุก 5 รอบ (ใช้ `roundWon` `Game.addLife`)
6. **คัดลอกผลการเล่น** ปุ่มที่หน้าสรุป คัดลอกสรุปผลภาษาไทยสั้น ๆ
7. **เหรียญของฉัน** เพิ่มเหรียญใหม่หนึ่งเหรียญ ด้วยการเพิ่มหนึ่งบรรทัดใน `BADGES` ที่ใช้กฎเดิม แต่เปลี่ยนตัวเลข

## ตรวจระบบ

หลังแก้ไฟล์ทุกครั้ง เปิดเกม กด **ตั้งค่า → ตรวจระบบ** ต้องขึ้นว่า "ผ่าน 12 จาก 12 ข้อ"
ถ้าไม่ผ่าน แปลว่าส่วนที่ห้ามแก้ (โซน C) เสียหาย ให้ย้อนกลับไปไฟล์ที่ commit ล่าสุด
หรือเปิดไฟล์ด้วย `?selfcheck=1` ต่อท้ายที่อยู่ (เช่น `index.html?selfcheck=1`) เพื่อให้ตรวจเองตอนเปิดหน้า

## เผยแพร่

1. ทำงานใน repo ที่ fork แล้ว `git add .` · `git commit -m "..."` · `git push`
2. ที่หน้า repo บน GitHub: Settings › Pages › Source: Deploy from a branch › `main` / root › Save
3. รอ 1 ถึง 2 นาที จะได้ลิงก์ `https://ชื่อบัญชี.github.io/ชื่อ-repo/`
4. เปิดลิงก์ในหน้าต่างไม่ระบุตัวตน เล่นหนึ่งรอบ และกดตรวจระบบ

เกมนี้ไม่เรียกอินเทอร์เน็ต ไม่เรียก AI ตอนเล่น และไม่เก็บข้อมูลส่วนตัว เก็บเฉพาะสถิติและการตั้งค่าในเบราว์เซอร์ของผู้เล่น
